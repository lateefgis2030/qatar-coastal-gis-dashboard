## 📌 Project Overview

The **Qatar Coastal GIS Dashboard** is a Personal GIS Portfolio Project developed to demonstrate the creation of an integrated coastal geospatial database, interactive Web GIS map, and ArcGIS Dashboard.

The project brings together coastal infrastructure, marine environmental features, and navigation-related assets into a single GIS environment for visualization, spatial understanding, and dashboard-based reporting.

The workflow demonstrates practical GIS skills from spatial data preparation and attribute management through web publishing and interactive dashboard development.

---

## 🎯 Project Objectives

- Develop a structured coastal GIS dataset for Qatar.
- Map important coastal and marine infrastructure.
- Represent marine environmental features spatially.
- Organize multiple GIS layers within a unified coastal information system.
- Publish GIS layers through ArcGIS Online.
- Configure an interactive Web Map.
- Develop an ArcGIS Dashboard for visual monitoring and reporting.
- Demonstrate an end-to-end GIS workflow suitable for a professional portfolio.

## 🌐 Web GIS & Dashboard

The processed GIS layers were published to **ArcGIS Online** and configured within an interactive Web Map.

An **ArcGIS Dashboard** was then developed to organize the information into major monitoring categories:

**Coastal Assets • Marine Environment • Infrastructure**

The dashboard provides a visual interface for exploring coastal GIS information and demonstrates how desktop GIS data can be transformed into an interactive Web GIS application.
