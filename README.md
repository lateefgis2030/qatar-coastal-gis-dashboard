---

## 📌 Project Overview

The **Qatar Coastal GIS Dashboard** is a Personal GIS Portfolio Project developed to demonstrate the creation of an integrated coastal geospatial database, interactive Web GIS map, and ArcGIS Dashboard.

The project brings together coastal infrastructure, marine environmental features, and navigation-related assets into a single GIS environment for visualization, spatial understanding, and dashboard-based reporting.

The workflow demonstrates practical GIS skills from spatial data preparation and attribute management through web publishing and interactive dashboard development.

---

## 🎯 Project Objectives

- Develop a structured coastal GIS dataset for Qatar.
- Map important coastal and marine infrastructure.
- Represent marine environmental features spatially.
- Organize multiple GIS layers within a unified coastal information system.
- Publish GIS layers through ArcGIS Online.
- Configure an interactive Web Map.
- Develop an ArcGIS Dashboard for visualization and reporting.
- Demonstrate an end-to-end GIS workflow suitable for a professional portfolio.

---

## 🗺️ GIS Dataset & Layers

The project integrates multiple coastal, environmental, and infrastructure datasets, including:

### Coastal Infrastructure

- Port Harbours
- Offshore Platforms
- LNG Facilities
- Marinas
- Industrial Coastal Zones
- Navigation Aids

### Marine Environment

- Marine Waters
- Islands
- Mangrove Areas
- Seagrass Beds
- Turtle Nesting Areas
- Coral Reefs
- Marine Protected Areas

### Reference Data

- Qatar Boundary
- Coastline

These datasets were organized and visualized within **ArcGIS Pro** before being published for Web GIS and dashboard development.

## 📊 ArcGIS Dashboard

The final dashboard integrates coastal assets, marine environmental information, and infrastructure into an interactive visualization environment.

Dashboard components include:

- Coastal asset indicators
- Marine environmental indicators
- Infrastructure statistics
- Interactive coastal map
- Marine Protected Area visualization
- Environmental asset charts
- Coastal infrastructure charts

The dashboard provides a centralized interface for exploring the spatial distribution and characteristics of Qatar's coastal GIS datasets.
